# WorkTool 使用与打包指南

本文档说明如何在开发环境启动 WorkTool，以及如何打包为 Windows 可执行文件分发给同事使用。

## 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| Python | 3.10 及以上（推荐 3.12） |
| 网络 | 首次安装依赖需要联网 |

## 一、首次环境准备

### 1. 安装 Python

若尚未安装 Python，可从 [python.org](https://www.python.org/downloads/) 下载，安装时勾选 **Add Python to PATH**。

安装完成后，在终端验证：

```powershell
python --version
```

应显示类似 `Python 3.12.x`。

### 2. 安装项目依赖

进入项目根目录：

```powershell
cd d:\WorkSpace\workTool
```

安装依赖（国内网络建议使用清华镜像）：

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 二、开发模式启动

在项目根目录执行：

```powershell
python main.py
```

成功后会打开 WorkTool 主窗口。左侧为工具列表，当前包含：

- **JSON 格式化**：JSON 美化、压缩、校验
- **接口调试**：HTTP/HTTPS 接口测试（类似 Postman）
- **AIHOT 资讯**：获取 [AIHOT](https://aihot.virxact.com/) 精选 AI 新闻、热点榜、日报
- **Markdown 预览**：粘贴 Markdown 源码并实时渲染
- **网址检索**：检索本机 Chrome / Edge 历史与书签并快速打开

关闭窗口即退出程序。

## 三、打包为 exe

WorkTool 使用 **PyInstaller** 打包，配置文件为项目根目录下的 `build.spec`。

### 打包命令

```powershell
cd d:\WorkSpace\workTool
python -m PyInstaller build.spec --noconfirm
```

### 产物位置

打包完成后，可执行文件位于：

```
dist\WorkTool.exe
```

将该文件复制给其他同事即可使用，**对方电脑无需安装 Python**。

### 使用者电脑要求（重要）

| 项目 | 要求 |
|------|------|
| 系统 | **Windows 10 / 11，64 位**（推荐已打最新补丁） |
| 不支持 | Windows 7、Windows 8 / 8.1 |

### 打包说明

- 单文件便携版，体积约 30~40 MB（含 PyQt5 运行时）
- 首次启动可能稍慢（需解压到临时目录），属正常现象
- 部分杀毒软件可能误报，可添加信任或通过内部软件审批流程分发

## 四、应用图标

图标文件路径：

```
assets\icon.ico
```

如需重新生成图标（修改配色或样式后）：

```powershell
python -m pip install pillow
python scripts\generate_icon.py
python -m PyInstaller build.spec --noconfirm
```

`build.spec` 中已配置 `icon='assets/icon.ico'`，重新打包后 exe 会带上新图标。

## 五、常见问题

### `python` 命令找不到

- 确认 Python 已安装且已加入 PATH
- 或重新打开终端 / Cursor 后再试
- 也可使用完整路径，例如：
  `C:\Users\<用户名>\AppData\Local\Programs\Python\Python312\python.exe main.py`

### pip 安装超时

使用国内镜像并延长超时：

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --default-timeout=120
```

### 打包后 exe 无法启动

1. 确认是在 Windows 64 位环境下打包
2. 查看 `build\build\warn-build.txt` 是否有缺失模块警告
3. 开发环境先执行 `python main.py` 确认程序本身可正常运行

### 报错「缺少 api-ms-win-core-path-l1-1-0.dll」

**原因：** 对方电脑系统过旧。WorkTool 使用 Python 3.12 打包，依赖 **Windows 10 及以上** 的系统 API，在 **Windows 7 / 8** 上无法运行。

**处理：** `Win + R` → 输入 `winver` → 确认是否为 Windows 10/11 64 位。若是 Win7/8，请升级系统或使用 Win10+ 电脑。

## 六、目录结构速查

```
workTool/
├── main.py              # 程序入口
├── build.spec           # PyInstaller 打包配置
├── requirements.txt     # Python 依赖
├── assets/
│   └── icon.ico         # 应用图标
├── app/                 # 应用源码
├── dist/
│   └── WorkTool.exe     # 打包产物（执行打包后生成）
└── docs/
    └── 使用与打包指南.md  # 本文档
```
