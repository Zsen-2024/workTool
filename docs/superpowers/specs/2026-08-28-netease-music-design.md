# 网易云听歌工具设计规格

## 目标

在 WorkTool 中新增「网易云听歌」工具：游客模式、应用内播放；支持热歌榜 / 新歌榜分页浏览与关键词搜索。不自建 API 服务，在客户端内直接调用网易云相关接口。

参考项目（能力参考，不照搬全量）：

- [ZainCheung/netease-cloud-api](https://github.com/ZainCheung/netease-cloud-api)
- [NeteaseCloudMusicApiEnhanced/api-enhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)
- [文档站](https://neteasecloudmusicapienhanced.js.org/#/?id=neteasecloudmusicapienhanced)

## 需求摘要

| 类别 | 内容 |
|------|------|
| 播放方式 | 应用内播放（QMediaPlayer） |
| 登录 | 不登录（游客） |
| 默认浏览 | Tab：热歌榜 \| 新歌榜 \| 搜索；榜单与搜索结果均分页 |
| 数据来源 | 自研精简 weapi 客户端，直接请求网易云；无 Node、无 pyncm |
| 架构 | 继承 `BaseToolWidget`，在 `registry.py` 注册 |

## 架构

新增目录 `app/tools/netease_music/`：

| 模块 | 职责 |
|------|------|
| `client.py` | 最小 weapi：榜单详情、云搜索、歌曲播放 URL（游客） |
| `worker.py` | 后台线程请求，避免阻塞 UI |
| `player.py` | 封装 `QMediaPlayer`：播/停、进度、音量、列表内上一首/下一首 |
| `widget.py` | 工具页 UI |
| `__init__.py` | 包导出 |

数据流：UI → Worker → `client` → 网易云 → 列表/URL → `player` 播放。

## UI 与交互

```
┌─────────────────────────────────────────┐
│ 网易云听歌（游客）                        │
│ [热歌榜] [新歌榜] [搜索]                  │
│ 搜索框（仅搜索 Tab）+ 搜索按钮            │
│ 歌曲列表（歌名 / 歌手 / 时长）+ 分页      │
│ 状态提示                                 │
├─────────────────────────────────────────┤
│ ▶/❚❚  当前曲目   进度条   音量            │
└─────────────────────────────────────────┘
```

| 交互 | 行为 |
|------|------|
| 打开工具 / 切到热歌·新歌 | 自动加载第 1 页（每页固定 30 首） |
| 双击行或点播放 | 取 URL 后底栏播放；失败则状态栏提示 |
| 搜索 Tab | 关键词搜索，结果分页 |
| 底栏 | 播放/暂停、进度、音量；当前列表内上一首/下一首 |

工具页注明：仅供个人学习测试，版权归网易云所有；游客仅可播免费/试听内容。

## 接口能力（最小集）

| 能力 | 用途 |
|------|------|
| 排行榜详情 | 热歌榜（榜单 id `3778678`）、新歌榜（`3779629`）分页列表 |
| 云搜索 | 按关键词搜歌曲并分页（`type=1` 单曲，每页 30 条） |
| 歌曲播放地址 | 按 song id 取可播 URL（优先标准音质，如 `br=128000` / `320000` 中可用者） |

实现约定：

- `client.py` 内完成 weapi 加密与必要请求头
- 不持久化 Cookie、不实现登录
- 继续使用 `requests`；播放用 PyQt5 多媒体模块

## 错误与边界

| 情况 | 处理 |
|------|------|
| 网络失败 / 超时 | 状态栏提示，保留上次列表 |
| 无版权 / 无 URL / 仅 VIP | 提示「暂无法播放」，不崩溃 |
| 空搜索词 | 不发起请求，提示输入关键词 |
| 快速切 Tab / 翻页 | Worker 取消或忽略过期结果，避免串台 |
| 媒体解码失败 | 提示播放失败 |

## 范围外（第一版不做）

登录、歌词、完整歌单体系、本地下载、评论、刷听歌量、自建/内嵌 Node API 服务。

## 验收标准

1. 侧栏出现「网易云听歌」，热歌榜 / 新歌榜可分页浏览
2. 搜索能出结果并分页
3. 点歌可在应用内播放、暂停、调节进度与音量
4. 无登录流程；失败有明确提示；不将歌曲文件下载到本地
